T-CITY WAVE 04.4 — T-БОНУСЫ В ГЛАВНОМ МЕНЮ

Собрано поверх T-CITY WAVE 04.3.

ИЗМЕНЕНИЕ
T-Бонусы больше не являются частью раздела «Гараж».

Главное меню теперь:
01 История бренда
02 Услуги и цены
03 Запись / Моя запись
04 Гараж
05 T-Бонусы

Справа от кнопки T-Бонусы сразу показывается текущий баланс.

Нажатие на T-Бонусы открывает отдельный экран кошелька:
- фирменная круглая монета T-CITY;
- текущий баланс;
- начислено за всё время;
- потрачено;
- история операций;
- правило 5% после завершённого визита.

ГАРАЖ
Большая карточка T-Бонусов из списка автомобилей удалена.
Гараж снова отвечает только за автомобили.

ПРОФИЛЬ КЛИЕНТА
В профиле оставлена компактная строка:
T-Бонусы   <баланс> T →
Она ведёт в тот же кошелёк.

Остальная логика Wave 04.3 не менялась:
- 5% кэшбэк;
- применение T-Бонусов при записи;
- Ждём вас → В работе → Готов → Завершено;
- актуальная дата в часовом поясе Тюмени для локального прототипа.
